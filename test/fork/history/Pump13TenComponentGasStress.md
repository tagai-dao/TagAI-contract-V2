# Pump13：10 成分主网 fork gas 压力测试

固定 BSC 区块 `120508054`。所有部署、买卖、补池和管理员授权仅在本地 fork 执行。

## 运行

先按 [基础 fork 测试说明](../Pump13Mainnet.md) 编译兄弟项目的 Basket V4。

```sh

# 预先按确定性地址分批创建空 V2 池
FOUNDRY_PROFILE=fork FOUNDRY_ETH_RPC_URL= forge test --isolate --match-contract Pump13GasStressForkTest --match-test test_gas_precreated -vv
```

## 两组场景

成分都是 QQQB、SPCXB、AAPLB、SKHYB、SPYB、NVDAB、TSLAB、MSFTB、HOODB、BABAB，各占 10%。

- A-WBNB：每种成分资产的外部价格池直接配 WBNB。
- A-USDT：每种成分资产的外部价格池直接配 USDT。

通过主网 Pancake V3 工厂获取或创建 1% 费档池，实际买入股票资产，再添加全范围流动性。
每个池子准备 20 BNB 买到的股票和 20 BNB 的报价资产；如该费档池已经存在，其原有价格和流动性继续存在。
这些是本地 fork 中构造的路径压力场景，不能把其收益率当作线上所有股票池的报价。
Pump 创建的十个成分池仍为 T-A；这些池子使用主网 Pancake V2 工厂。

## gas 计量

使用 `--isolate` 将顶层调用按独立交易执行，避免沿用前一笔交易的脏存储和瞬态状态。每个被测操作先在可回滚快照中预演，记录整个调用树访问的账户。恢复快照后，将这些账户及其存储槽标为冷访问，再单独执行同一操作。
记录该外部调用的 `gasLimit - gasRemaining`，加上 21,000 基础 gas 和 calldata 的零/非零字节开销，作为 Foundry 隔离模式的 gas 估算。判断是否可执行以受限调用是否成功为准，不把工具报告值直接当作钱包的最低 gasLimit，也不依靠退款来让耗尽 gas 的调用完成。
授权、价格查询和报价池准备不混入交易计量。LP 添加采用测试协调器；LP 撤出单列 pair.burn，先前 LP 转入单独发生。

正常操作最多分配 16,600,000 执行 gas，并检查估算的单笔总量小于 BSC 的 16,777,216 上限。
创建十成分已知超过上限，为测试其后续逻辑，仅创建这一步允许更高的本地执行额度，并明确断言它超过主网上限。
因此后续测试通过不意味着当前十成分创建流程可以直接上线。

覆盖创建、内盘买卖/最后一买、上市、V4 买卖、跨周期 Nutbox 注入、首次和后续指数回购、代领、奖励后的转账、指数买卖、LP 添加/质押/解押/撤出，以及奖励启用后的 5 BNB 大额买单。

该方法复现冷存储访问，并用限额调用筛查上限；它不是完整节点的交易准入或跨所有 tick 分布的最坏情况证明。

## 前端聚合路由

测试聚合器 [ForkSplitBuyRouter.sol](../../helpers/ForkSplitBuyRouter.sol) 只接收资金分配数组并执行，不在链上搜索。

- 路由 0：BNB → T，直接走 T-BNB V4。
- 路由 1–10：BNB → A → T，最后一步走对应成分 V2 池。
- 每笔分别投入 0.1、1、5 BNB，两种外部报价池共六个场景。
- 另外分别在 A-WBNB / A-USDT 场景启用实际回购分红，再测 1 BNB 聚合买入，覆盖奖励记账的额外成本。

比较全部 V4、11 路平均分配、按边际实际到账贪心优化三种策略。报价通过快照内的真实交易模拟获取，使用 20 份资金、5% 分配粒度；共享池的价格变化和 T 的 0.1% V2 税均参与模拟。
优化后的整笔分配会重新完整报价，并在三种候选中保留到账最多的方案，然后测量一次合约执行的 gas。
所有策略都从相同池状态开始，检查实际到账等于报价、聚合器没有截留 T/BNB，以及不可满足的最小接收量使整笔拆单回滚。

这里的“优化”是离散近似，比较目标是收到更多 T，尚未把用户实际 gas 价格折算进收益，也不代表连续分配的全局最优。
测试适配器没有作为生产路由器部署；授权模型、残余资产回收及更多交易方向需要生产实现各自的测试。

## 预建空池可避开创建时的 gas 上限

主网 V2 `createPair` 每个池约 322 万 gas，是直接创建十成分超限的主要来源。当前 Pump 使用 CREATE2 clone，可由 Pump、Token implementation、创建者和 salt 预测 T 地址。V2 工厂允许先对未来地址创建空池，Pump 随后会复用它们。

| 分笔操作 | 单笔估算 gas |
|---|---:|
| 预建前 3 个空池 | 9,676,926 |
| 预建中间 3 个空池 | 9,676,940 |
| 预建最后 4 个空池 | 12,883,182 |
| 创建十成分 T、社区和质押池 | 4,817,102 |
| 内盘结束后上市 | 9,838,727 |

该路径已通过，验证了实际 T 地址、空 LP 状态、十个质押池绑定，以及最终上市。总工作量分到多笔交易；前三笔用测试批处理协调器模拟，尚未接入生产前端。准备阶段不需要募集内盘资金；创建者、salt、implementation 必须与最终创建一致。
