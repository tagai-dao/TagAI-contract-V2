# Pump12 Layer 4 — BondDepository 与 PremiumSeller 执行清单

**目标：** 为每个 Token 在 Listing 时固定 BondDepository 与 PremiumSeller，完成 USDG Bond、2 天归属和高溢价协议卖出补墙。

## 1. Treasury 与部署

- [x] 全局 Bond/Premium 实现只配置一次；Listing 时 clone、原子初始化并固化 Treasury 权限。
- [x] Treasury 分模块累计 `mintedByBond`、`mintedByPremium`，统一执行 BurnNet freeze/TWAP/同 poke 时间戳门禁。

## 2. BondDepository

- [x] 固定 `price = max(TWAP × 97%, anchor)`，支持用户 `maxPrice`。
- [x] USDG 100% 通过 Hook 的指定 poolId Pending 入口进入 BurnNet，且永远 non-eligible。
- [x] payout 在合约内 2 天线性归属，按 note 独立领取。
- [x] 每 8 小时上限为 epoch 起始供应量 0.25%；每 30 天上限为 period 起始供应量 5%。

## 3. PremiumSeller

- [x] `TWAP > 2 × anchor`、成功执行间隔至少 1 小时。
- [x] clip 只读取基础永久 POL 当前 Token inventory 的 0.25%。
- [x] Treasury mint 后在官方 v4 池 exact-input 卖出，至少满足用户 minOut 和 TWAP 下方 1% 的双重保护。
- [x] 卖出净得 USDG 100% 进入对应 BurnNet Pending 且 non-eligible。
- [x] PremiumSeller 的协议自售免 Hook 交易费，避免平台/创建者分走补墙资金或形成 eligible credit。

## 4. 验收

- [x] 单测覆盖价格贴 Anchor、折扣、双周期快照额度、归属与领取。
- [x] 单测覆盖 2× 边界、1 小时间隔、POL clip、滑点、fee exemption 和 Pending 分类。
- [x] 覆盖 downward reset 统一冻结、恶意调用、跨池隔离。
- [x] 完整本地回归、Robinhood fork 和合约 size 检查通过；等待提交指令。
