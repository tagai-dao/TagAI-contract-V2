# Pump12 Layer 3 — Treasury、Staking 与 Distributor 执行清单

**目标：** 在 Listing 时为每个 Token 原子创建唯一 Treasury、sToken、Staking 和 Distributor，完成固定 mint 权限、8 小时质押快照和受 TWAP/credit 双重约束的排放闭环。

**约束：** 经济参数遵循 `docs/PUMP12_NETNET_BURNNET_SPEC_CN.md`；Treasury 是 Token 上市后的唯一 minter；任何无效 TWAP、BurnNet 冻结或零质押状态都不得 mint；non-eligible USDG 不得形成 reserve credit。

## 1. 固定模块与 mint 权限

- [x] Listing 时先 clone 全部 Layer 3 模块，再一次性初始化循环依赖。
- [x] Token 上市后仅 Treasury 可 mint，Pump12、TagAI 与创建者均无 mint 路径。
- [x] Treasury 只接受固定 Distributor 调用，并记录 `mintedByDistributor`。
- [x] Treasury 在统一入口检查 BurnNet 的 24 小时冻结和 post-reset TWAP。

## 2. sToken 与 Staking

- [x] sToken 使用可 rebase 的 gon/share 会计，只允许其 Staking mint、burn、rebase。
- [x] `stake` 先处理到期 epoch，再 1:1 接收 Token/发行 sToken；`unstake` 同样先 rebase。
- [x] warmup 固定为 0；用户只需跨过全局快照，无个人 8 小时锁定。
- [x] 每次调用最多推进一个 8 小时 epoch；没有 sToken 时不请求或消耗发行信用。

## 3. Distributor

- [x] 仅 Staking 可调用 `distribute`；每个 epoch 最多调用一次。
- [x] `rate = 0.45% × clamp((TWAP/emissionAnchor - 1)/0.75, 0, 1)`。
- [x] `emissionAnchor = max(initialAnchor, currentAnchor)`；无效 TWAP或价格不高于门槛时排放为 0。
- [x] credit = `37.5M + eligible reserve / initialAnchor + actual burn - totalMinted`，饱和减法。
- [x] reserve credit 只读最近一次有效 poke 快照减去该快照后的 eligible 消耗；以 initialAnchor 固定折算。

## 4. 验收

- [x] 覆盖零质押、零 premium、线性区、0.45% 饱和、credit clamp 和耗尽恢复。
- [x] 覆盖 stake/rebase/unstake 边界、新质押不能追领刚到期奖励及多 epoch 不一次跳过。
- [x] 覆盖 downward reset 24 小时冻结与完整 post-reset TWAP 解冻。
- [x] 覆盖 non-eligible Pending 不增加 credit，eligible 消耗与实际 burn 不双计。
