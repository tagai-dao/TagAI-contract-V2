# Pump12 Layer 5 — pTEAM、IndexBondDesk 与 IndexFund 执行清单

**目标：** 完成无 strike 的 pTEAM 发行、溢价认购 Desk、官方指数资产自动购买与 1%/99% 变现分账，并在 Listing 时永久绑定可插拔 Fund 实现。

## 1. pTEAM 与 Treasury

- [x] Treasury 仅授权固定 pTEAM 增发并独立累计发行量。
- [x] `listTime + 24h`、有效 TWAP `>= 1.2 × anchor`、BurnNet 可增发时才能行权。
- [x] 累计行权不超过当前总供应量 10%；单次行权后 Desk 未售库存不超过新总供应量 0.5%。

## 2. IndexBondDesk

- [x] 固定认购价 `max(TWAP × 93.5%, 1.2 × anchor)`，支持用户 `maxPrice`。
- [x] `anchor × N` 原额进入 BurnNet Pending，不抽 1%；溢价部分原子交给 IndexFund。
- [x] 用户取得独立 2 天线性归属票据；已售未领取数量不算未售库存。
- [x] 无管理员提款、改价或转移库存路径。

## 3. IndexFund Factory / V1

- [x] Factory 只允许 Pump12 创建 clone；TagAI 只能更新未来 Listing 使用的实现。

- [x] Desk 溢价到账后同交易买入 IndexToken；失败则整个认购回滚。
- [x] 仅创建者可卖 IndexToken 或领取 holder fee；WETH holder fee 同交易经官方 ETH/USDG Hub 变现。
- [x] 变现 USDG 固定 1% 给创建者收款地址、99% 进入 BurnNet Pending，且全部 non-eligible。
