**Goal:** 在 `rh` 上开 `rh-v10v11`，按三期把 main 的 V11 发行行为、V10 导入补齐、Index Broker NFT 移植到 Robinhood，最后一次性发布。

**Architecture:** RH 保持 Uniswap v4 / `NutboxDeployConfig` / 现有曲线与 4.8 ETH 上市参数。从 `main` 只迁行为与 Index Broker 合约逻辑；Pancake Vault 路径全部重写成 Uniswap v4。导入继续长在 `TagAISwapWrapper` 上。

**Tech Stack:** Solidity 0.8.26、Foundry、Uniswap v4-core、OpenZeppelin 4.9、solady。参考提交：`main` 上 Pump V11 源码 `a573440`，当前 `rh` HEAD 为工作起点。

## Global Constraints

- 基线分支必须是 `rh`，工作分支名 `rh-v10v11`。
- Uniswap v4 `unlockCallback` + `src/utils/CurrencySettler.sol`；禁止 `lockAcquired` / BSC Vault。
- Pump 构造函数保持 `(address ipshare, address feeReceiver, NutboxDeployConfig cfg)`。
- 曲线 `a = 1_624_898_729`；`LISTING_ETH_BUDGET = 4.8 ether`；`LISTING_TICK_LOWER = -887220`；`LISTING_TICK_UPPER = 205740`；`LISTING_LIQUIDITY_DELTA` 保持 RH 现值。
- 上市 `PoolKey.fee = 3000`；`tickSpacing = 60`。
- `collectFees` 分配：ETH 0.5% 调用者、其余平台；Token LP Fee → `listingHook`。
- 不删除 `TagAISwapWrapper`；Wrapper ETH 费率默认 100/100 bps。
- ImportHelper 保留 IPShare 强制创建，以及调用方传入 calculator / policy。
- 不覆盖 RH NFT Mining / Basket Mining / ERC20 staking / locking。
- 不写 `deployments/56/`。
- 三期代码可以合在同一分支，但主网广播只允许在第 3 期测试全部通过之后。
