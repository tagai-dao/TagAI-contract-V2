# RH V14 默认股票清单

来源为用户指定的 [Uniswap RH 股票页](https://app.uniswap.org/explore/tokens/robinhood?category=stocks)，通过其公开的 `ListRwas` 目录读取，逐地址区分发行方。目录包含 215 只股票、260 个 RH 代币地址。

## 选择口径

- 单个池子的官方美元 TVL **严格大于 50,000**，不累加小池、不用市值或交易量替代；TVL 不等于指定滑点下的成交深度。
- 当前部署接入 Uniswap V3 / 无 Hook、固定费率 V4，报价币为 USDG 或 WETH，费率小于 5%，当前活跃流动性大于零。同一地址选符合条件且 TVL 最大的池。
- V3 核验 factory、factory.getPool、token0/token1、fee、liquidity；V4 核验完整 PoolKey 哈希、已初始化 slot0 和活跃 liquidity；核验所有股票及报价币 decimals。
- USDG/WETH 中转池同样经过 TVL、factory 和活跃流动性检查。WETH 报价股票可直接兑 ETH，经中转池兑 USDG；USDG 报价股票路径相反。
- 所有 50 个入选股票均由 Robinhood 发行；Anchored 地址没有符合本口径的池。其余地址未加入，原因逐项保存在 manifest。
- 原有 SPY、QQQ 属于 ETF，不冒充股票。两者也满足同一门槛，因此保留已有支持。V11 的固定九项配置不变。

本次部署使用的采集完成时间：`2026-10-08T04:04:13.998139+00:00`；链上验证区块：`83020129`，哈希 `0xcfdc3f8521078253aed90b435f8d55b1eacde015e792e25c07e01bd3ded3ba99`。

## 部署行为

`script/config/RHVersion14StockConfig.sol` 由同一 manifest 生成 52 个成分地址和 53 个价格池，生成 105 条双向路由。`DeployRHPump14.s.sol` 在转移所有权之前按每组最多 16 项批量写入 Router，并通过 Pump 构造函数一次写入全部成分；无需用户手填股票地址。没有修改 BasketSwapRouter 或 BuybackRouter 的业务逻辑。

Router 初始化采用 4 笔池配置和 7 笔路由配置，避免过长的构造参数和单笔初始化 gas；Pump 52 项白名单在构造时一次完成，当前 initcode 大小由测试及部署前检查保证。必须等全部交易成功且完成脚本输出的多签操作后，才能切换生产入口。仅运行生成/测试命令不部署合约。

快照超过 24 小时会被部署脚本拒绝。全新部署前刷新目录和池子数据、重新做链上核验并检查生成 diff；本次部分部署恢复须保留冻结清单，不能刷新后混用。具体命令见 RH_VERSION14.md。生成脚本只读 RPC，没有私钥输入或广播行为。链上校验固定在一个区块；美元 TVL 采用接口快照，二者不是同一区块的原子价格证明。
